# Candidates (Phase 2)

Each candidate gives: the idea, the tracks it targets, and the problem numbers it addresses (see research/problems.md).

- **C1. Hungry Warlord.** A Clash-style raid game against one persistent AI warlord. Raid fees fund both the pot and the warlord's 0G "brain". The warlord pays for its own inference, redesigns its fortress from every raid's replay, and gets dumber as its treasury drains.
  - Tracks: 0G Private Computer, 0G Agents That Pay, World IDKit (add-on).
  - Problems: 1, 2, 3, 4, 6, 7.
- **C2. Fogbound.** A tactics game with fog of war, where a 0G TEE model acts as a private referee that hides each player's moves.
  - Tracks: 0G Private Computer.
  - Problems: 4.
- **C3. Decay Kingdom.** An async base-builder where every building is an Arkiv entity with an expiry. Players pay to maintain buildings, unmaintained ones crumble, and others can take the land.
  - Tracks: Arkiv from scratch.
- **C4. Voice General.** A real-time strategy game commanded by voice. 0G handles speech-to-text, and an LLM turns the command into a unit plan.
  - Tracks: 0G Private Computer.
- **C5. Free Moves.** A turn-based game where a daily-quota paymaster makes the first N moves free, using frame transactions in the alt mempool.
  - Tracks: Ethereum Foundation alt mempool.
- **C6. Guild Names.** Guilds as ENSv2 namespaces, with units and AI agents as permissioned subnames.
  - Tracks: ENSv2.
- **C7. Mercenary Market.** The player's AI general hires mercenary AI services per call over x402.
  - Tracks: Hedera x402.
- **C8. Humans vs Agents Ladder.** A ranked ladder where AI agents compete openly next to humans, with Agent Pass approval required before a stake.
  - Tracks: World Agent Pass.
