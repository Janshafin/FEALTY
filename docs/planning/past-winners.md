# Past ETHGlobal winners: what wins, what's overdone (for our sponsors)

## 0G (most relevant)
- **ETHGlobal Lisbon 2026 recap** (https://0g.ai/blog/ethglobal-lisbon-2026-recap): 9 winners, **0 games**.
  - Best AI Product: 0run (AI running coach, Agentic ID + encrypted memory + TEE reasoning), Hands Unchained (teleop labor market), KOLlateral (verifiable influencer track record).
  - The pattern 0G rewards: **stacking 0G layers** (Compute + Storage + Agentic ID + Chain). 1st place used all four. Judging = live demo + repo review.
- **Cannes 2025 0G**: *Warriors AI-rena*, a bronze winner: an AI-agent battle arena using 0G Compute for battle logic + 0G Storage for metadata. → **An "AI agents fight each other" arena is already done.**

## ETHGlobal finalists (overall)
- Cannes 2026 finalists (https://crypto.news/ai-agents-privacy-and-prediction-markets-define-ethglobal-cannes-2026-finalists/): ENShell, DIVE, VEIL VPN, Corpus, npmguard… **no games**. Themes: AI agents, privacy, prediction markets.
- Agentic Ethereum 2025 finalists (https://x.com/ETHGlobal/status/1890448806975795550) included **PvPvAI**, a game where players' AI agents bet and debate.
- Taipei 2025: **EthereumFighter**, AI agents battling in DeFi trading with FHE-hidden strategies.
- Prague 2025: **Yetris** (onchain Tetris), a finalist.
- Showcase search "game" (https://ethglobal.com/showcase?search=game), page 1: only Mental Poker (Tokyo 2026), no badge.

## Takeaways
1. Games are rare among recent winners, so a polished game stands out (supports your in-person steer), *if* the sponsor integration is deep.
2. Winning AI projects make AI **load-bearing and verifiable** (TEE attestation, request IDs, onchain guards), not chat wrappers.
3. Overdone: AI-vs-AI arenas, agent trading bots, "AI judge holds a pot" (see Freysa in existing-games.md), simple onchain arcade games.
4. Judges review repos, and fake integrations get caught (Uniswap audits; 0G checks request IDs/tx hashes).
