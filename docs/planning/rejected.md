# Rejected ideas and why

- **C2 Fogbound:** An LLM referee isn't deterministic, so it's a bad fit for hidden-information rules. ZK, as Dark Forest uses, is the real fix. The AI is also removable: a plain server could referee just as well. That fails 0G's "AI can't be removable" requirement.
- **C3 Decay Kingdom:** Expiry is a genuinely strong reason to use Arkiv. But a persistent world needs a population, the demo would be an empty map in a 36-hour hackathon, and it isn't fun within 3 minutes. Possible future add-on: store raid replays on Arkiv with an expiry.
- **C4 Voice General:** The chain isn't essential, which fails test (b). Research prototypes already exist: arXiv 2508.16580, HIVE, rts-commander.
- **C5 Free Moves:** EF judges score how the project relates to the alt mempool, so the game would just be decoration. It also depends on devnet-only tooling, and the alt-mempool tooling hasn't been checked.
- **C6 Guild Names:** ENS would be bolted on and the core loop has no game in it, which fails test (b).
- **C7 Mercenary Market:** x402 is pay-per-HTTP-request, so a "mercenary" service is contrived. A judge wouldn't play it for fun.
- **C8 Humans vs Agents Ladder:** I couldn't find public "Agent Pass" docs (searched 2026-11-05; only AgentKit beta at docs.world.org/agents turned up). Its core dependency can't be verified. The idea is close to Warriors AI-rena (Cannes 2025) and Secret.Quest (Brussels).

**C1 survives.** See final.md.
